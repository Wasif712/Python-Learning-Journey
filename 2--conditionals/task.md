# Mini Project — Student Performance System

Input: 
Student name, Marks, Attendance

Rules:
Marks <0 or >100 → Invalid
Attendance <0 or >100 → Invalid
Marks>=50 AND Att>=75 → Pass
Marks>=80 AND Att>=85 → Excellent Performance
Otherwise → Needs Improvement

# Your Practice Tasks

## Task 2 — Pass / Fail: User se marks lo. marks >= 50 → Pass, otherwise → Fail
## Task 3 — Grade Calculator: 90+ → A, 80+ → B, 70+ → C, 60+ → D, 50+ → E, <50 → F
## Task 4 — Scholarship: Marks >= 80 AND Attendance >= 75 → Eligible, otherwise → Not Eligible
## Task 5 — Data Validation: User se percentage lo. Valid: 0–100, Invalid: <0 or >100
